# FinanceMe - Your Personal Finance Tracker (財務管理應用程式)

這是一個用於個人財務管理的手機版網站應用程式，基於 React 和 TypeScript 開發。旨在幫助您追蹤和管理您的股票投資、外幣資產、現金以及貸款資訊，並在儀表板上提供總覽。

## 開發進度 (Development Progress)

*   專案初始化 (Vite + React + TypeScript)。
*   基礎數據服務 (`dataService.ts`)：用於模擬本地數據 (numbers.json) 的讀寫操作。
*   主要功能模塊的基礎頁面及路由已搭建：儀表板、股票投資、外幣投資 / 定存 / 現金、貸款。
*   「股票投資」模塊已實現基本功能：新增股票、模擬自動獲取股票資訊、手動輸入購買成本及股數、自動計算當前價值及損益。
*   **目前：所有數據操作均為前端內存模擬，無法直接讀寫本地 `numbers.json` 檔案。實際應用需要後端服務或桌面環境支持。**

## 功能介紹 (Features)

FinanceMe 包含以下四大功能模塊：

### 1. 儀表板 (Dashboard)

*   **功能：** 提供您所有財務模塊的總覽。顯示總資產、總負債，並可能透過圖表來區分不同資產類別的佔比。
*   **目的：** 讓您快速了解整體財務健康狀況。

### 2. 股票投資 (Stock Investments)

*   **功能：**
    *   **新增股票：** 輸入股票代號或名稱。
    *   **自動資訊獲取：** 應用程式會嘗試模擬自動帶出股票的名稱、當前股價。
    *   **自定義輸入：** 您可以輸入您的購買成本和持有的股數。
    *   **即時計算：** 自動計算當前股票的總價值和損益 (包含損益百分比)。
*   **目的：** 追蹤您的股票投資表現，了解每筆投資的盈虧情況。

### 3. 外幣投資 / 定存 / 現金 (Foreign Currency / Fixed Deposits / Cash)

*   **功能：** 管理您持有的各種外幣資產，包括外幣投資、定期存款和外幣現金。允許記錄不同幣種的金額、匯率等資訊。
*   **目的：** 全面掌握您的外幣資產配置和價值。

### 4. 貸款 (Loans)

*   **功能：** 記錄您的貸款資訊，例如貸款總額、已償還金額、剩餘金額、利率等。
*   **目的：** 幫助您管理債務，追蹤還款進度。

---

**備註：**

*   本專案仍在開發初期，所有數據目前僅在瀏覽器內存中操作，**未實現與本地 `numbers.json` 檔案的實際交互**。
*   股票即時數據目前為**模擬數據**。若需真實數據，需要整合外部金融數據 API。
